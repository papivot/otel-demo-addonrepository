# OTEL DEMO HELM ADDONREPOSITORY

## Source [https://opentelemetry.io/docs/platforms/kubernetes/helm/demo/]

The Open Telemetry Demo is a *microservice-based distributed system* intended to illustrate the implementation of OpenTelemetry (observability) in a near real-world environment. As part of that effort, the OpenTelemetry community create the OpenTelemetry Demo Helm Chart so that it can be easily installed in Kubernetes.
